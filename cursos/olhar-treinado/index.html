O que você vai conseguir fazer

Como este curso ensina

O curso treina o olho com comparações: a mesma cena em estéticas diferentes, a mesma foto com uma decisão alterada, referências desmontadas camada por camada. Abaixo de cada imagem está o prompt que a gerou — é o seu vocabulário crescendo.

Seu projeto

Você monta seu caderno de olhar: boards anotados, uma biblioteca de palavras visuais, três estudos de recriação e um conjunto de regras pessoais aplicadas a uma série de imagens.

Todas as imagens de exemplo foram geradas para este curso com o GPT Image, da OpenAI — pela ferramenta de imagem do Codex e pelo modelo GPT Image na Magnific. Abaixo de cada uma está o prompt exato que a produziu. Comparações do tipo “muda só X” (e as sete estéticas) foram feitas editando a mesma imagem-base, para que só a variável estudada mude. Pessoas e lugares retratados são fictícios.
