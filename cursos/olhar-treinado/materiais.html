Materiais de trabalho

Olhar Treinado: prompts das práticas, fichas e rubrica do projeto.

  • prompts.txt — todos os prompts das práticas guiadas, com o critério de verificação.
  • caderno-de-olhar.md — modelo completo do caderno de olhar, seção por seção: cadeia de decisão, 3 boards, 10 referências anotadas, 10 palavras-chave, blocos de estilo v1 e v2, desmontagem, estudo, recriação, 5 regras, série e grade regra × imagem.
  • guia-7-esteticas.md — tabela de referência das sete famílias estéticas — o que cada uma comunica, quando usar, palavras de prompt e armadilhas — mais híbridos, ordem no prompt e as 5 perguntas para reconhecer uma estética.
  • prompt-visual-dna.md — prompt pronto para um assistente com visão extrair o DNA visual de uma marca a partir de imagens: cadeia elemento → função → meta-mensagem → emoção, paleta com papéis, legenda de DNA e bloco de estilo.
  • rubrica.md — rubrica do projeto final (6 critérios × 3 níveis, total de 18 pontos), leitura do resultado, checklist de entrega e como separar feedback de gosto de falha real.

Os arquivos acima são modelos para preencher, não leitura. Baixe, duplique para cada projeto e mantenha a data e a versão no topo — o caderno é um documento vivo.

Guarde o prompt junto da imagem

Em todas as seções do caderno, cole o prompt exato ao lado de cada imagem. Sem o prompt, a imagem é um resultado; com ele, é uma decisão que você pode repetir.

Sobre as imagens

Todas as imagens de exemplo foram geradas para este curso com o GPT Image, da OpenAI — pela ferramenta de imagem do Codex e pelo modelo GPT Image na Magnific. Abaixo de cada uma está o prompt exato que a produziu. Comparações do tipo “muda só X” (e as sete estéticas) foram feitas editando a mesma imagem-base, para que só a variável estudada mude. Pessoas e lugares retratados são fictícios.

Os textos foram escritos para o INEMA.CLUB a partir de estudo do acervo de referência; nenhuma imagem, vídeo ou apostila de terceiros foi copiada.
