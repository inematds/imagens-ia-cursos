# Rubrica do projeto final

Avalie **linha por linha**. Para cada critério, marque o nível e anote a evidência (qual arquivo prova). Qualquer linha em "Em construção" é a primeira coisa a refazer.

| Critério | Em construção | Pronto para cliente | Nível portfólio | Seu nível | Evidência |
|---|---|---|---|---|---|
| **Briefing e tradução** | briefing genérico; estilo = gosto pessoal | 5–7 frases claras; adjetivos, referências e uso definidos | constantes técnicas derivadas do briefing; negativos vindos do que o cliente não quer | | |
| **Prompt e controle** | prompt de uma linha; variações mudam várias coisas | mestre com seis camadas; variações A e B mudam uma camada cada | ciclo de comparação escrito, com as palavras de maior efeito identificadas | | |
| **Sistema (JSON + preset)** | não existe ou é o prompt copiado | JSON com variáveis e preset com "pode / não pode" | preset testado por outra pessoa e corrigido | | |
| **Edição** | antes/depois sem uso definido | uso e formato definidos; edições estruturais e de conteúdo documentadas | edição invisível em 100%; nota de fluxo com o que melhoraria | | |
| **Coerência da série** | imagens soltas; luz e paleta variando | seis peças com luz, paleta e personagem constantes | variedade de planos com papéis claros; nenhuma peça destoa lado a lado | | |
| **Entrega e apresentação** | arquivos sem nome; um formato só | formatos por plataforma, nomes no padrão, fichas de geração | prancha + case com texto de apresentação e próximos passos | | |

## Checagem rápida antes de enviar

- [ ] Rostos da série conferidos lado a lado com a imagem-mestre, em 100%
- [ ] Mãos, dedos e anatomia conferidos
- [ ] Todo texto (rótulo, placa, preço) lido letra por letra
- [ ] Formatos e pixels de cada plataforma; área segura do vertical respeitada
- [ ] sRGB para tela; perfil pedido pela gráfica para impressão
- [ ] Nomes no padrão `cliente_campanha_peca_variacao_versao_formato-largura.ext`
- [ ] Ficha de geração ao lado de cada arquivo final
- [ ] Prancha, case e texto de apresentação revisados

## Como usar

1. Preencha sozinho, com evidências.
2. Escolha **uma** linha para levar a "Nível portfólio" nesta rodada.
3. Peça a um colega que avalie com a mesma tabela e compare.
4. Guarde a rubrica preenchida na pasta do projeto.
